# Referências de interface da Associação Atlética Cocari

O site atual usa HTML, CSS e JavaScript puro: index.html, style.css, app.js e icons.js.

Ao trabalhar nas interfaces, consulte os MCPs configurados quando forem úteis:

- Watermelon: referências de componentes, blocos e composição de páginas.
- shadcn: consulte os registries @prompt-kit, @motion-primitives e @watermelon.
- gsap-master: exemplos e orientação sobre animações GSAP; é um servidor comunitário.

O components.json serve para consulta de catálogos. Ele não significa que o site tenha React ou Tailwind instalados. Consulte e adapte referências à estrutura atual. Uma instalação direta de componentes React exige uma migração de stack explicitamente solicitada pelo usuário.

Ao implementar animações, preserve as interações existentes e respeite prefers-reduced-motion. Consulte a documentação oficial do GSAP para confirmar APIs sugeridas pelo servidor comunitário.
